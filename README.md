
# Password Strength Checker

## Project Description
The Password Strength Checker is a Python-based application that evaluates password strength using different conditions.

## Features
- Checks password length.
- Checks uppercase letters.
- Checks lowercase letters.
- Checks numbers.
- Checks special characters.
- Calculates a score out of 5.
- Displays password strength as Weak, Medium, or Strong.
- Provides suggestions to improve password strength.

## Technologies Used
- Python 3
- Pydroid 3

## How It Works
The program asks the user to enter a sample password. It checks five conditions and calculates a score out of 5. Based on the score, it displays the password strength.

## How to Run
1. Open the password_checker.py file.
2. Run the program using Python.
3. Enter a sample password.
4. View the strength result.

## Conclusion
This project demonstrates Python concepts such as conditional statements, loops, string methods, and input/output operations.
